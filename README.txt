Year 1 Scan and Watch

Files
  watch.html   The student page. Deploy it as a full-screen Web Clip.
  qrscan.js    QR code reader written in-house. No outside code.
  common.js    Checks the code holds a YouTube video link.

Making the cards
  Make QR codes in Canva (or any tool) from the plain YouTube video link.
  Scan one with a phone first to check it shows the YouTube address and not a short link.

Hosting
  Put the three files in the same folder on an HTTPS site (for example GitHub Pages).
  The camera does not work over plain HTTP.
  The web filter needs to allow the hosting address and youtube-nocookie.com.
